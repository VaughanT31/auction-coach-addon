# Commands

*Every Auction Coach chat command.*

| Command | What it does |
|---|---|
| `/ac` | Open or close the Auction Coach window |
| `/ac plan` | Open Today's Plan |
| `/ac auctions` | See which of your auctions are undercut |
| `/ac accounting` | Where your gold comes from and goes |
| `/ac gold` | Your gold and AH sales over time |
| `/ac gph` | Gold per hour for a farming session (`/ac gph start`, `pause`, `stop`) |
| `/ac repost` | Open the repost list at the Auction House |
| `/ac shop add [item] 12.5` | Add an item to your shopping list with the most you'll pay |
| `/ac shop remove [item]` | Remove an item from your shopping list |
| `/ac shop alerts` | Turn shopping list alerts on or off |
| `/ac destroy` | What it has learned about milling, prospecting and disenchanting |
| `/ac scan` | Scan the Auction House now (it must be open), even inside the 15 minute wait |
| `/ac status` | What the scanner is doing |
| `/ac tooltip` | Turn the tooltip advice on or off |
| `/ac sales` | Turn the sale messages on or off |
| `/ac guard` | Turn vendor and delete protection on or off |
| `/ac export` | Copy your items as a string for the website |
| `/ac import` | Paste a prices string from the website |
| `/ac options` | Open the options, including your seller style |
| `/ac help` | List every command |

The minimap button opens the window too. Right-click it for the options, Shift-click it for gold per hour.
